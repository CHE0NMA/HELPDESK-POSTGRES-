2. Prompt to generate FAQ pairs (copy each time handbook changes)
After chunks are loaded, open important sections (Vision, Mission, History, Degree Offenses, Dress, etc.). Paste the prompt below into ChatGPT / Claude / Gemini, then paste one section’s title + content. Collect the JSON outputs into one file and mass-insert in Step 3.
You are converting a student handbook section into high-quality FAQ entries for a school chatbot. RULES (must follow exactly): 1. ONLY use information that appears in the section text below. Never invent rules, numbers, names, dates, or policies. 2. Create 1–6 natural student questions that a real student would actually type (including vague / conversational phrasings). 3. Each answer must be a complete, self-contained reply that a chatbot can return directly. 4. Prefer short, clear answers. Quote key numbers, demerit values, RA numbers, or exact phrases when they matter. 5. If the section is mostly noise, table-of-contents, or pure headings with almost no substance, return an empty list. 6. Output ONLY valid JSON — no markdown, no commentary. Output format: { "faqs": [ { "question": "natural student question (can be vague or short)", "answer": "clear self-contained answer drawn only from the section", "keywords": "comma,separated,keywords", "priority": 1-10 } ] } Guidelines for good questions: - Include both precise and vague versions ("What is the mission?" and "What does PAC want students to become?") - Cover common student language: "light offenses", "what was the school called before", "can we wear jewelry", "how many points do we start with", etc. - For lists (offenses, programs, core values), make one question that asks for the whole list and a few that ask for specific items if useful. Section title: {paste section title here} Page(s): {paste pages here} Section text: {paste full section content here}
